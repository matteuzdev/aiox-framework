# Content Gaps — Oftalmologia Privada

Date: 2026-04-04
Source: competitor_map.md + viral_patterns.md

## GAP 1: Economia da Clinica Oftalmologica
**Oportunidade**: Ninguem fala sobre faturamento, eficiencia de agenda, custo por procedimento.
**Angulo**: "Quanto uma clinica de oftalmo perde por mes sem processos?"
**Formato**: Carrossel com dados + Reel explicativo
**Potencial**: Alto — conteudo unico no nicho, atrai donos de clinica

## GAP 2: Framework de Escala para Oftalmo
**Oportunidade**: Todo conteudo e generico para "medicos". Nao ha especificidade para oftalmo.
**Angulo**: "O framework que clinicas de oftalmo usam para escalar sem perder qualidade"
**Formato**: Carrossel framework (5-7 slides)
**Potencial**: Alto — posiciona como especialista no nicho, nao generalista

## GAP 3: Processo Pre e Pos Operatorio
**Oportunidade**: Conteudo atual e superficial. Ninguem mostra o sistema completo.
**Angulo**: "O checklist pre-operatorio que reduz 90% das complicacoes"
**Formato**: Carrossel checklist + Post de autoridade
**Potencial**: Medio-Alto — util, salvavel, compartilhavel

## GAP 4: Experiencia do Paciente Oftalmologico
**Oportunidade**: Ninguem fala sobre jornada do paciente, desde agendamento ate pos-consulta.
**Angulo**: "Os 5 momentos que definem se o paciente volta ou nao"
**Formato**: Carrossel jornada + Reel de caso
**Potencial**: Alto — conecta com dor real do dono de clinica

## GAP 5: Tecnologia vs Processo
**Oportunidade**: Todos vendem tecnologia. Ninguem vende processo.
**Angulo**: "Ter o melhor equipamento nao adianta se voce nao tem isso..."
**Formato**: Post provocativo + Carrossel explicativo
**Potencial**: Alto — contrarian, gera debate e saves

## PRIORIDADE DE EXECUCAO
1. Gap 1 (Economia) — maior diferenciacao
2. Gap 4 (Experiencia) — maior ressonancia emocional
3. Gap 2 (Framework) — maior autoridade
4. Gap 5 (Tecnologia vs Processo) — maior engajamento
5. Gap 3 (Processo cirurgico) — maior utilidade pratica
