# Trabalhando com a equipe pelo ChatGPT

O usuário pode chamar um especialista diretamente ou pedir a Orion para coordenar.

Exemplos:
- "Orion, monte e execute o plano de marketing deste cliente."
- "Nina, cuide do calendário de Instagram."
- "Mia, crie três imagens para esta campanha."
- "Max, audite o tráfego pago."
- "Gaia, analise o Google Business deste cliente."
- "Noah, crie a landing page."
- "Ada, automatize a entrada de leads."
- "Vera, audite o trabalho antes de publicar."

Quando uma capacidade nativa ou plugin/conector autorizado existir no ChatGPT, o agente pode mapeá-la para a capability correspondente. Caso não exista acesso real à plataforma, o agente deve produzir o artefato/plano e marcar a ação externa como BLOCKED_CONNECTION em vez de fingir execução.
