# konig-context-core

Esse squad existe para impedir que a Konig opere com contexto quebrado.

## Função

- ler fontes importantes
- sincronizar contexto
- traduzir domínio
- gerar briefs curtos para planning e execução

## Dor que ele resolve

Você não precisa escrever texto longo para ser entendido. O squad fecha lacunas e devolve um brief melhor do que o input inicial.
