# Carrossel Spec

Formato: Instagram feed carousel

- dimensao: `1080x1350`
- proporcao: `4:5`
- uso: feed vertical
- nao e: slide deck `16:9`

## Nota

Os arquivos foram desenhados para carrossel de feed, nao para apresentacao.
O termo `slide` foi usado apenas como nome sequencial de pagina.
