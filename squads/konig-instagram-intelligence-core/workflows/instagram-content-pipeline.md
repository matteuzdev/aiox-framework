# instagram-content-pipeline

Fluxo de producao editorial completo: da analise competitiva a publicacao.

1. `analyze-instagram-competition`
2. `build-editorial-war-map`
3. `produce-carousel-batch`
4. `write-caption-batch`
5. `run-social-quality-gate`
6. `publish-to-instagram`

Uso:

- quando precisa gerar conteudo de autoridade para um nicho
- quando ha um objetivo comercial claro (vendas, leads, posicionamento)
- quando o lote precisa passar por gate de qualidade antes de publicar

Entrada minima:

- niche: segmento de mercado (ex: oftalmo, dentist, fitness)
- objective: o que queremos com este conteudo (autoridade, vendas, leads)
