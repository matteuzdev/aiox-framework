# konig-revenue-core

Esse squad cuida de caminho de oferta e sistema de funnel da Konig.

## Função

- desenhar oferta
- organizar caminho de monetização
- estruturar funnel para SaaS, serviços, digital, físico ou COD

## Dor que ele resolve

Evita abrir uma frente comercial sem lógica de oferta, valor e conversão.
