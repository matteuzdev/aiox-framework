# athenaeum-cycle

Fluxo base:

1. `frame-strategic-brief`
2. `map-stakeholder-tensions`
3. `build-systems-reading`
4. `assess-human-and-cultural-factors`
5. `run-ethics-and-reputation-check`
6. `generate-strategic-scenarios`
7. `detect-invisible-patterns`
8. `consolidate-strategic-narrative`
9. `produce-executive-synthesis`

Uso:

- quando a situacao e ambigua
- quando ha muitos stakeholders
- quando a decisao tem custo politico, cultural ou reputacional
