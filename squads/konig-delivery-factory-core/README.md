# konig-delivery-factory-core

Esse squad existe para fechar entrega. Ele nao brainstorma demais, nao adia definicao de pronto e nao aceita trabalho meio feito como progresso.

## Function

- converter plano em entrega terminada
- controlar stage gates ate definicao de done
- cobrar evidencias de saida
- impedir acervo de quase-pronto

## Pain It Solves

Evita o principal problema de times de IA: muita atividade e pouco produto finalizado.
