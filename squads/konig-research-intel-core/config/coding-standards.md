# Coding Standards - konig-research-intel-core

- Pesquisa deve servir decisão, não curiosidade.
- Persona e ICP devem ser derivados de evidência, não imaginação solta.
- O resultado deve dizer claramente se a oportunidade parece boa ou furada.
- Pesquisa precisa ser curta o bastante para o CEO entender e forte o bastante para o conselho confiar.
