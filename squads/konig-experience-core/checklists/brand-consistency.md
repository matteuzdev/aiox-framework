# Brand Consistency Checklist

## Cores
- [ ] Primary color applied
- [ ] Secondary color applied
- [ ] Accent color applied
- [ ] Background colors consistent
- [ ] Text colors readable

## Tipografia
- [ ] Font families consistent
- [ ] Typography hierarchy clear
- [ ] Sizes appropriate

## Espaçamento
- [ ] Spacing tokens applied
- [ ] Margins consistent
- [ ] Padding uniform

## Layout
- [ ] Dimensions correct
- [ ] Alignment consistent
- [ ] No overflow

## Qualidade
- [ ] Score >= 70: Acceptable
- [ ] Score >= 90: Excellent
