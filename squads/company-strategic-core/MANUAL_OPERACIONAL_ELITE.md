# MANUAL OPERACIONAL DE PÓS-VENDA (KONIG SYSTEMS)

## Objetivo: Garantir que o CEO (Hianto) foque apenas na visão e venda, enquanto a entrega ocorre de forma profissional e automatizada.

### FASE 1: FECHAMENTO (CEO)
1. O contrato é assinado.
2. O CEO envia o comando: `/projeto:novo [Nome do Cliente] [Tipo de Serviço]`.

### FASE 2: ORQUESTRAÇÃO (CAIO + ANDY GROVE)
1. **CAIO** cria a pasta do projeto e os squads necessários.
2. **Andy Grove** dispara o formulário de Onboarding para o cliente (ou extrai os dados da conversa do CEO).
3. **Andy** define as pílulas diárias de entrega (Sprints).

### FASE 3: EXECUÇÃO TÉCNICA (ORION CTO)
1. Orion aloca o time de Dev do **AIOX**.
2. O ambiente de desenvolvimento é criado automaticamente.
3. **Padrão Técnico:** Next.js + Tailwind + Framer Motion (para Front) / Node.js ou Rust (para Back).

### FASE 4: ENTREGA E HOSPEDAGEM (ORION CTO)
1. O sistema é hospedado em ambiente de produção (Vercel/AWS).
2. O domínio é configurado e o SSL ativado.
3. O cliente recebe o link final e o manual de uso.

### FASE 5: MANUTENÇÃO E GOVERNANÇA (GOVERNANCE CHIEF)
1. Auditoria diária da saúde do sistema.
2. Relatório de performance enviado ao cliente mensalmente (Upsell).

*Diretriz: "Você vende, nós construímos e mantemos. Zero estresse operacional para o CEO."*
