# Team Gate Checklist

## Pre-Execution
- [ ] Workflow identificado
- [ ] Squads necessários mapeados
- [ ] Dependencies verificadas
- [ ] Triade alinhada

## Execution
- [ ] Cada stage iniciado
- [ ] Handoffs entre squads funcionando
- [ ] blockers identificados
- [ ] Métricas sendo coletadas

## Post-Execution
- [ ] Resultados documentados
- [ ] Lições aprendidas registradas
- [ ] Próximos steps definidos
- [ ] Revenue/impact medido
