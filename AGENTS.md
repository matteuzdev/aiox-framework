# AGENTS.md - Synkra AIOX (Codex CLI)

Este arquivo define as instrucoes do projeto para o Codex CLI.

<!-- AIOX-MANAGED-START: core -->
## Core Rules

1. Siga a Constitution em `.aiox-core/constitution.md`
2. Priorize `CLI First -> Observability Second -> UI Third`
3. Trabalhe por stories em `docs/stories/`
4. Nao invente requisitos fora dos artefatos existentes
5. Toda passagem de bastao entre agentes ou squads DEVE ser visivel no output operacional
<!-- AIOX-MANAGED-END: core -->

## Visible Handoff Protocol

Quando houver troca real de ownership, o agente em execucao DEVE registrar um bloco curto e visual no output:

```text
[HANDOFF]
de: <agent-or-squad>
para: <agent-or-squad>
objetivo: <o que o proximo dono precisa concluir>
artefatos: <arquivos, links ou saidas entregues>
criterio_de_aceite: <como o proximo dono sabe que recebeu direito>
status: ready | blocked
[/HANDOFF]
```

Regras:
- Nao simular handoff quando nao houve troca real de ownership
- Nomear explicitamente quem assumiu e quem entregou
- Citar o artefato passado, nao apenas a intencao
- Se houver bloqueio, marcar `status: blocked`
